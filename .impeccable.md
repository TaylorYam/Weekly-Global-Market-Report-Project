## Design Context

### Users
Recruiters exploring a portfolio without cloning a repository. The main task is to open either a historical report or a reproducible synthetic demonstration.

### Brand Personality
Clear, restrained, editorial. Use the existing navy report identity and the owner's plain-language positioning.

### Aesthetic Direction
Lightweight static page, warm paper background, navy text, serif headline and readable sans-serif body. Two prominent report links, with no external assets or scripts.

### Design Principles
- Make the two examples distinguishable before the visitor clicks.
- Keep source verification and human approval explicit.
- Use readable contrast, visible keyboard focus and responsive spacing.
- Preserve the historical report's layout except for the owner's approved edits.
